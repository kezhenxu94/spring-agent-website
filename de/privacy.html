Dies ist eine Übersetzung. Weicht sie von der englischen Fassung ab, ist die englische Fassung maßgeblich.

Kurz gesagt: Mit deinem eigenen Agent-Server erheben wir keine Daten von dir. Spring Agent hat weder Analysefunktionen noch Werbung noch Tracking. Die App kommuniziert ausschließlich mit dem Agent-Server, bei dem du dich anmeldest, und übermittelt diesem Server das, worum du deinen Agenten bittest. Wählst du Spring Agent Cloud, ist dieser Server unserer: Was er speichert und wohin er es sendet, steht unter Spring Agent Cloud.

Diese Richtlinie gilt für die App Spring Agent für iPhone und iPad („die App“), entwickelt von kezhenxu94 („wir“, „uns“).

Dein Agent-Server

Die App ist ein Client für einen Spring Agent-Server: einen, den du selbst betreibst, den deine Organisation für dich betreibt oder – mit Spring Agent Cloud – den wir betreiben. Bei der Anmeldung wählst du diesen Server aus. Ab diesem Zeitpunkt übermittelt die App ihm deine Nachrichten, die von dir angehängten Dateien, deine Einstellungen sowie die Ergebnisse aller Tools auf diesem iPhone, deren Nutzung du deinem Agenten erlaubst.

Betreibst du oder deine Organisation den Server, betreiben wir ihn nicht und erhalten keine dieser Daten. Was der Server mit deinen Daten tut – einschließlich der Frage, an welche Anbieter von KI-Modellen er deine Unterhaltungen übermittelt –, entscheidet dessen Betreiber; maßgeblich sind dessen Richtlinien.

Du meldest dich über die eigene Anmeldeseite deines Servers an. Das dabei erhaltene Zugriffstoken speichert die App im iOS-Schlüsselbund auf deinem Gerät.

Spring Agent Cloud

Spring Agent Cloud ist ein Agent-Server, den wir im Rahmen eines Abonnements für dich betreiben, unter cloud.springagent.kezhenxu94.me. Du meldest dich dort mit „Mit Apple anmelden“ an; das dabei erhaltene Zugriffstoken speichert die App im iOS-Schlüsselbund auf deinem Gerät.

Um deinen Agenten zu betreiben, speichert der Server, was die App ihm wie oben beschrieben übermittelt, außerdem, was dein Agent zwischen Unterhaltungen behält – geplante Aufgaben, Erinnerungen, Skills und Wissensdokumente – sowie die Schlüssel, die du für Konnektoren eingibst.

Um dir zu antworten, übermittelt der Server deine Nachrichten und alles auf diesem iPhone, was du deinen Agenten verwenden lässt, an den externen KI-Anbieter, den er nutzt. Dem stimmst du bei der Registrierung zu.

Damit du erfährst, wenn dein Agent dieses iPhone braucht, dir eine Frage stellt oder eine Antwort fertig ist, speichert der Server das Push-Token dieses Geräts, verknüpft mit deinem Konto, und sendet Mitteilungen über den Apple Push Notification Service. Eine Mitteilung kann den Anfang einer Antwort oder Frage sowie den Tool-Namen und die Argumente einer Anfrage enthalten; diese Argumente gehen außerdem in einer stillen Mitteilung über Apple, damit das iPhone eine von dir erlaubte Aktion im Hintergrund ausführen kann. Beim Abmelden bittet die App den Server, das Token zu entfernen. Mitteilungen kannst du jederzeit in den iOS-Einstellungen deaktivieren.

Daten auf diesem iPhone

Wenn eine Aufgabe dieses iPhone erfordert, bittet dein Agent die App, ein Tool zu verwenden, etwa um deinen Standort zu ermitteln, ein Kalenderereignis oder eine Erinnerung zu lesen oder hinzuzufügen, einen Wecker zu stellen, Health-Daten zu lesen oder einzutragen, einen Kontakt nachzuschlagen, ein aktuelles Foto zu finden oder eine E-Mail oder Nachricht zu entwerfen. Die App:

  • verwendet jede Art von Daten erst, nachdem iOS dich um die entsprechende Berechtigung gebeten und du sie erteilt hast;
  • richtet sich nach der Auswahl, die du für jedes Tool unter „Einstellungen“ › „Auf diesem iPhone“ triffst – „Erlaubt“, „Vorher fragen“ oder „Aus“;
  • übermittelt das Ergebnis ausschließlich an deinen Agent-Server, und zwar für die Aufgabe, die es angefordert hat;
  • übermittelt es niemals an uns oder an Dritte – außer an unseren Server und dessen KI-Anbieter, wenn du Spring Agent Cloud nutzt.

Du kannst all dies unter „Einstellungen“ › „Auf diesem iPhone“ deaktivieren und jede Berechtigung jederzeit in den iOS-Einstellungen widerrufen.

Gesundheitsdaten

Daten aus Apple Health werden nur gelesen oder geschrieben, wenn dein Agent darum bittet und du es erlaubst, und werden ausschließlich für diese Anfrage an deinen Agent-Server übermittelt; bei Spring Agent Cloud gibt dieser Server sie nur an seinen KI-Anbieter weiter, um diese Anfrage zu beantworten. Sie werden niemals für Werbe- oder Marketingzwecke verwendet, niemals verkauft, von uns niemals zu anderen Zwecken weitergegeben und von der App niemals in iCloud gespeichert.

Konnektoren

Konnektoren werden auf deinem Agent-Server konfiguriert. API-Schlüssel oder Tokens, die du für einen Konnektor eingibst, werden an deinen Server übermittelt und dort gespeichert; bei Spring Agent Cloud ist das unser Server.

Beispielagent

„Ohne Server ausprobieren“ startet einen integrierten Beispielagenten. In diesem Modus verlässt nichts dein iPhone.

Käufe

Spring Agent Pro und Spring Agent Cloud werden über den App Store verkauft. Die Zahlung wird von Apple abgewickelt; wir erhalten keine Zahlungsdaten. Ob du Pro besitzt, prüft die App mit StoreKit von Apple auf deinem Gerät. Für Spring Agent Cloud übermittelt die App unserem Server zusätzlich den vom App Store signierten Kaufbeleg, damit er dein Abo bei Apple prüfen kann. Wir können von Apple aggregierte, anonyme Verkaufsberichte einsehen.

Was wir nicht tun

  • Abgesehen von Spring Agent Cloud, falls du es wählst, betreiben wir keine Server, die Daten von der App empfangen.
  • Die App enthält keine SDKs für Analyse, Werbung oder Absturzberichte.
  • Wir verfolgen dich nicht über Apps oder Websites hinweg, verkaufen keine Daten und geben sie nicht für Werbung weiter.

Kinder

Die App richtet sich nicht an Kinder unter 13 Jahren, und wir erheben wissentlich keine Daten von ihnen.

Änderungen

Wenn sich diese Richtlinie ändert, wird die neue Fassung hier mit einem neuen Gültigkeitsdatum veröffentlicht.
