隐私政策

生效日期：2026 年 11 月 11 日

本文为译文。如与英文版本不一致，以英文版本为准。

简而言之：使用你自己的智能体服务器时，我们不收集你的数据。春信（Spring Agent）没有分析、没有广告，也没有跟踪。本 App 只与你所登录的智能体服务器通信，并将你要求智能体执行的内容发送给该服务器。如果你选择 Spring Agent Cloud，该服务器由我们运营：它保存哪些内容、发送到哪里，请参阅 Spring Agent Cloud。

本政策适用于由 kezhenxu94（“我们”）开发的 iPhone 和 iPad 版春信 App（“本 App”）。

你的智能体服务器

本 App 是 Spring Agent 服务器的客户端，该服务器由你自行运行、由你所在的组织为你运行，或者作为 Spring Agent Cloud 由我们运行。登录时，由你选择该服务器。此后，本 App 会将你的消息、你附加的文件、你的设置，以及你允许智能体使用的这台手机上任何工具的结果发送给该服务器。

如果服务器由你或你所在的组织运营，我们不运营该服务器，也不会收到上述任何内容。服务器如何处理你的数据（包括将你的对话发送给哪些 AI 模型服务商）由其运营者决定，并受其政策约束。

你通过服务器自身的登录页面登录。本 App 将由此获得的访问令牌保存在你设备上的 iOS 钥匙串中。

Spring Agent Cloud

Spring Agent Cloud 是我们以订阅方式为你运营的智能体服务器，地址为 cloud.springagent.kezhenxu94.me。你通过“通过 Apple 登录”登录该服务器，本 App 将由此获得的访问令牌保存在你设备上的 iOS 钥匙串中。

为运行你的智能体，服务器会保存本 App 按上文所述发送给它的内容，以及你的智能体在对话之间保留的内容（定时任务、记忆、技能和知识文档），还有你为连接器输入的密钥。

为回答你，服务器会将你的消息，以及你允许智能体使用的这台手机上的任何内容，发送给它所使用的第三方 AI 服务商。你在注册时会同意这一点。

为在智能体需要使用这台手机、向你提问或回答准备好时通知你，服务器会保存本设备的推送令牌（与你的账户关联），并通过 Apple 推送通知服务（APNs）发送通知。通知可能包含回答或问题的开头部分，以及请求的工具名称和参数；这些参数还会通过 Apple 以静默通知的形式传递，以便手机在后台运行你已允许的操作。退出登录时，本 App 会请求服务器删除该令牌。你可以随时在 iOS“设置”中关闭通知。

这台手机上的数据

当某项任务需要用到这台手机时，你的智能体会请求本 App 使用某个工具，例如查找你的位置、读取或添加日历日程或提醒事项、设置闹钟、读取或记录“健康”数据、查找联系人、查找最近的照片，或起草邮件或信息。本 App：

  • 仅在 iOS 已就每类数据请求权限、且你已授予该权限后，才会使用该类数据；
  • 遵循你在“设置 › 在这台 iPhone 上”中为每个工具所作的选择——允许、每次询问或关闭；
  • 仅将结果发送给你的智能体服务器，用于请求该结果的任务；
  • 绝不会将其发送给我们或任何其他人；但使用 Spring Agent Cloud 时，会发送给我们的服务器及其 AI 服务商。

你可以在“设置 › 在这台 iPhone 上”中关闭上述全部功能，也可以随时在 iOS“设置”中撤回任何权限。

健康数据

来自 Apple“健康”的数据仅在你的智能体请求且你允许时才会被读取或写入，并且仅会为该请求发送给你的智能体服务器；使用 Spring Agent Cloud 时，该服务器仅为回答该请求而将其交给其 AI 服务商。这些数据绝不会被用于广告或营销，绝不会被出售，绝不会由我们为任何其他目的共享，也绝不会由本 App 存储在 iCloud 中。

连接器

连接器在你的智能体服务器上配置。你为连接器输入的任何 API 密钥或令牌都会发送到你的服务器并存储在那里；使用 Spring Agent Cloud 时，该服务器就是我们的服务器。

示例智能体

“无需服务器即可试用”会运行内置的示例智能体。在该模式下，任何内容都不会离开你的手机。

购买

Spring Agent Pro 和 Spring Agent Cloud 通过 App Store 销售。付款由 Apple 处理；我们不会收到任何付款信息。本 App 在你的设备上通过 Apple 的 StoreKit 检查你是否已开通 Pro。对于 Spring Agent Cloud，本 App 还会将 App Store 签名的购买记录发送给我们的服务器，以便其向 Apple 核验你的订阅。我们可能会看到 Apple 提供的汇总、匿名的销售报告。

我们不做的事

  • 除你选择使用的 Spring Agent Cloud 外，我们没有任何接收本 App 数据的服务器。
  • 本 App 不包含任何分析、广告或崩溃报告 SDK。
  • 我们不会跨 App 或网站跟踪你，不会出售数据，也不会为广告目的共享数据。

儿童

本 App 并非面向 13 岁以下儿童，我们不会在知情的情况下收集他们的数据。

变更

如本政策发生变更，新版本将在此处发布，并注明新的生效日期。
