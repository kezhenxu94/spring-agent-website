要約：お客様ご自身のエージェントサーバをご利用の場合、当方はお客様のデータを収集しません。Spring Agentには、アナリティクス、広告、トラッキングは一切ありません。本アプリが通信する相手は、お客様がサインインしたエージェントサーバのみであり、そのサーバには、お客様がエージェントに依頼した内容を送信します。Spring Agent Cloudを選択した場合、そのサーバは当方が運用します。保存する内容と送信先はSpring Agent Cloudをご覧ください。

本ポリシーは、kezhenxu94（以下「当方」といいます）が提供するiPhoneおよびiPad向けアプリ「Spring Agent」（以下「本アプリ」といいます）を対象とします。

エージェントサーバ

本アプリは、お客様ご自身が運用する、お客様の組織がお客様のために運用する、またはSpring Agent Cloudとして当方が運用するSpring Agentサーバのクライアントです。お客様はサインイン時にそのサーバを選択します。以後、本アプリは、お客様のメッセージ、添付ファイル、設定、およびお客様がエージェントに使用を許可したこのiPhone上のツールの実行結果を、そのサーバに送信します。

お客様またはお客様の組織がサーバを運用する場合、当方はそのサーバを運用しておらず、これらの情報を一切受け取りません。サーバがお客様のデータをどのように取り扱うか（会話をどのAIモデルプロバイダに送信するかを含みます）は、そのサーバの運用者が決定し、その運用者のポリシーに従います。

サインインは、お客様のサーバ自身のサインインページで行います。その結果取得したアクセストークンは、本アプリがお客様のデバイス上のiOSキーチェーンに保管します。

Spring Agent Cloud

Spring Agent Cloudは、当方がサブスクリプションによりお客様のために運用するエージェントサーバ（cloud.springagent.kezhenxu94.me）です。サインインには「Appleでサインイン」を使用し、その結果取得したアクセストークンは、本アプリがお客様のデバイス上のiOSキーチェーンに保管します。

エージェントを動作させるため、サーバは、上記のとおり本アプリから送信された内容に加え、エージェントが会話をまたいで保持する内容（スケジュールされたタスク、メモリ、スキル、ナレッジドキュメント）と、お客様がコネクタ用に入力したキーを保存します。

お客様に回答するため、サーバは、お客様のメッセージと、お客様がエージェントに使用を許可したこのiPhone上の情報を、サーバが利用する第三者のAIプロバイダに送信します。お客様は登録時にこれに同意します。

エージェントがこのiPhoneを必要とするとき、質問があるとき、または回答の準備ができたときにお知らせするため、サーバは、このデバイスのプッシュトークンをお客様のアカウントに紐付けて保存し、Apple Push Notification serviceを通じて通知を送信します。通知には、回答や質問の冒頭部分、およびリクエストのツール名と引数が含まれる場合があります。これらの引数は、お客様が許可した操作をiPhoneがバックグラウンドで実行できるよう、サイレント通知としてもAppleを経由します。サインアウトすると、本アプリはサーバにトークンの削除を求めます。通知はiOSの「設定」でいつでもオフにできます。

このiPhone上のデータ

タスクにこのiPhoneが必要な場合、エージェントは本アプリにツールの使用を求めます。たとえば、現在地の取得、カレンダーのイベントやリマインダーの読み取りまたは追加、アラームの設定、ヘルスケアデータの読み取りまたは記録、連絡先の検索、最近の写真の検索、メールやメッセージの下書き作成などです。本アプリは：

  • 各種データを、iOSが許可を求め、お客様がそれを許可した後にのみ使用します。
  • 「設定」›「このiPhoneで」でツールごとにお客様が選んだ設定（「許可」「毎回確認」「オフ」）に従います。
  • 結果を、それを求めたタスクのためにのみ、お客様のエージェントサーバにのみ送信します。
  • 当方を含め、他の誰にも送信しません。ただし、Spring Agent Cloudをご利用の場合は、当方のサーバおよびそのAIプロバイダに送信されます。

これらはすべて「設定」›「このiPhoneで」でオフにでき、またiOSの「設定」でいつでも各許可を取り消すことができます。

ヘルスケアデータ

Appleの「ヘルスケア」のデータは、エージェントが求め、お客様が許可した場合にのみ読み取りまたは書き込みが行われ、その要求のためにのみお客様のエージェントサーバに送信されます。Spring Agent Cloudでは、そのサーバは当該要求に回答するためにのみ、このデータをAIプロバイダに渡します。このデータが広告やマーケティングに使用されることはなく、販売されることもなく、当方がその他の目的で共有することもなく、本アプリがiCloudに保存することもありません。

コネクタ

コネクタはお客様のエージェントサーバ上で設定されます。コネクタのために入力したAPIキーやトークンは、お客様のサーバに送信されてそこに保存されます。Spring Agent Cloudの場合、そのサーバは当方のものです。

サンプルエージェント

「サーバなしで試す」では、内蔵のサンプルエージェントが動作します。このモードでは、iPhoneの外に送信されるものは一切ありません。

購入

Spring Agent ProおよびSpring Agent CloudはApp Storeを通じて販売されます。支払いはAppleが処理し、当方が支払い情報を受け取ることはありません。本アプリは、お客様がProを利用できるかどうかを、デバイス上でAppleのStoreKitを用いて確認します。Spring Agent Cloudの場合、本アプリは、App Storeが署名した購入記録を当方のサーバにも送信し、サーバがAppleにサブスクリプションを確認できるようにします。当方は、Appleから集計された匿名の売上レポートを閲覧することがあります。

当方が行わないこと

  • お客様が選択した場合のSpring Agent Cloudを除き、当方は、本アプリからデータを受け取るサーバを保有していません。
  • 本アプリには、アナリティクス、広告、クラッシュレポートのSDKは含まれていません。
  • 当方は、アプリやWebサイトをまたいでお客様をトラッキングせず、データを販売することも、広告目的で共有することもありません。

お子様

本アプリは13歳未満のお子様を対象としておらず、当方がお子様から故意にデータを収集することはありません。

変更
