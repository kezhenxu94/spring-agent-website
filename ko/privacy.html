요약: 사용자 본인의 에이전트 서버를 사용하는 경우, 당사는 사용자의 데이터를 수집하지 않습니다. Spring Agent에는 분석, 광고, 추적이 없습니다. 앱은 사용자가 로그인한 에이전트 서버와만 통신하며, 사용자가 에이전트에게 요청한 내용을 해당 서버로 전송합니다. Spring Agent Cloud를 선택하면 그 서버는 당사가 운영합니다. 무엇을 보관하고 어디로 보내는지는 Spring Agent Cloud를 참조하세요.

본 방침은 kezhenxu94(이하 “당사”)가 만든 iPhone 및 iPad용 Spring Agent 앱(이하 “앱”)에 적용됩니다.

사용자의 에이전트 서버

앱은 사용자가 직접 운영하거나, 사용자의 조직이 사용자를 위해 운영하거나, Spring Agent Cloud로서 당사가 운영하는 Spring Agent 서버의 클라이언트입니다. 사용자는 로그인할 때 해당 서버를 선택합니다. 그 이후 앱은 사용자의 메시지, 첨부한 파일, 설정, 그리고 사용자가 에이전트에게 사용을 허용한 이 iPhone의 도구 실행 결과를 해당 서버로 전송합니다.

사용자 또는 사용자의 조직이 서버를 운영하는 경우, 당사는 해당 서버를 운영하지 않으며 이러한 데이터를 전혀 받지 않습니다. 서버가 사용자의 데이터를 어떻게 처리하는지 — 사용자의 대화를 어떤 AI 모델 제공업체에 전송하는지를 포함하여 — 는 해당 서버의 운영자가 결정하며, 그 운영자의 정책이 적용됩니다.

사용자는 서버 자체의 로그인 페이지를 통해 로그인합니다. 앱은 그 결과로 받은 액세스 토큰을 사용자 기기의 iOS 키체인에 보관합니다.

Spring Agent Cloud

Spring Agent Cloud는 당사가 구독을 통해 사용자를 위해 운영하는 에이전트 서버(cloud.springagent.kezhenxu94.me)입니다. 사용자는 'Apple로 로그인'으로 로그인하며, 앱은 그 결과로 받은 액세스 토큰을 사용자 기기의 iOS 키체인에 보관합니다.

에이전트를 실행하기 위해 서버는 위에서 설명한 대로 앱이 전송한 내용과 함께, 에이전트가 대화 사이에 보관하는 내용(예약된 작업, 메모리, 스킬, 지식 문서) 및 사용자가 커넥터에 입력한 키를 저장합니다.

사용자에게 답변하기 위해 서버는 사용자의 메시지와, 사용자가 에이전트에게 사용을 허용한 이 iPhone의 정보를 서버가 이용하는 제3자 AI 제공업체로 전송합니다. 사용자는 가입할 때 이에 동의합니다.

에이전트에게 이 iPhone이 필요할 때, 질문이 있을 때, 또는 답변이 준비되었을 때 알려 드리기 위해, 서버는 이 기기의 푸시 토큰을 사용자의 계정에 연결하여 저장하고 Apple 푸시 알림 서비스(APNs)를 통해 알림을 보냅니다. 알림에는 답변이나 질문의 앞부분, 그리고 요청의 도구 이름과 인수가 포함될 수 있습니다. 이 인수는 사용자가 허용한 작업을 iPhone이 백그라운드에서 실행할 수 있도록 무음 알림으로도 Apple을 거칩니다. 로그아웃하면 앱이 서버에 토큰 삭제를 요청합니다. 알림은 언제든지 iOS 설정에서 끌 수 있습니다.

이 iPhone의 데이터

작업에 이 iPhone이 필요한 경우, 에이전트는 앱에 도구 사용을 요청합니다. 예를 들어 위치 확인, 캘린더 이벤트나 미리 알림 읽기 또는 추가, 알람 설정, 건강 데이터 읽기 또는 기록, 연락처 조회, 최근 사진 찾기, 메일이나 메시지 초안 작성 등이 있습니다. 앱은:

  • 각 종류의 데이터를 iOS가 권한을 요청하고 사용자가 그 권한을 허용한 후에만 사용합니다.
  • ‘설정 › 이 iPhone에서’에서 각 도구에 대해 사용자가 선택한 사항(허용됨, 매번 묻기 또는 끔)을 따릅니다.
  • 결과를 해당 결과를 요청한 작업을 위해 사용자의 에이전트 서버로만 전송합니다.
  • 결과를 당사나 그 밖의 누구에게도 전송하지 않습니다. 단, Spring Agent Cloud를 사용하는 경우에는 당사의 서버와 그 AI 제공업체로 전송됩니다.

사용자는 ‘설정 › 이 iPhone에서’에서 이 모든 기능을 끌 수 있으며, 언제든지 iOS 설정에서 모든 권한을 철회할 수 있습니다.

건강 데이터

Apple 건강의 데이터는 에이전트가 요청하고 사용자가 허용한 경우에만 읽거나 기록되며, 해당 요청을 위해 사용자의 에이전트 서버로만 전송됩니다. Spring Agent Cloud에서는 해당 서버가 그 요청에 답하기 위해서만 이 데이터를 AI 제공업체에 전달합니다. 이 데이터는 광고나 마케팅에 절대 사용되지 않고, 절대 판매되지 않으며, 당사가 그 밖의 목적으로 절대 공유하지 않고, 앱이 iCloud에 절대 저장하지 않습니다.

커넥터

커넥터는 사용자의 에이전트 서버에서 구성됩니다. 사용자가 커넥터에 입력하는 모든 API 키나 토큰은 사용자의 서버로 전송되어 그곳에 저장됩니다. Spring Agent Cloud의 경우 그 서버는 당사의 서버입니다.

샘플 에이전트

“서버 없이 체험하기”는 내장된 샘플 에이전트를 실행합니다. 이 모드에서는 어떠한 데이터도 사용자의 iPhone 밖으로 나가지 않습니다.

구입

Spring Agent Pro와 Spring Agent Cloud는 App Store를 통해 판매됩니다. 결제는 Apple이 처리하며, 당사는 결제 정보를 받지 않습니다. 앱은 사용자 기기에서 Apple의 StoreKit을 사용하여 Pro 보유 여부를 확인합니다. Spring Agent Cloud의 경우, 앱은 App Store가 서명한 구입 기록을 당사 서버에도 전송하여 서버가 Apple을 통해 구독을 확인할 수 있게 합니다. 당사는 Apple로부터 익명의 집계된 판매 보고서를 받아볼 수 있습니다.

당사가 하지 않는 일

  • 사용자가 선택한 Spring Agent Cloud를 제외하면, 당사에는 앱으로부터 데이터를 받는 서버가 없습니다.
  • 앱에는 분석, 광고 또는 충돌 보고 SDK가 포함되어 있지 않습니다.
  • 당사는 앱이나 웹사이트를 넘나들며 사용자를 추적하지 않으며, 데이터를 판매하거나 광고 목적으로 공유하지 않습니다.

아동

앱은 13세 미만 아동을 대상으로 하지 않으며, 당사는 아동으로부터 고의로 데이터를 수집하지 않습니다.
